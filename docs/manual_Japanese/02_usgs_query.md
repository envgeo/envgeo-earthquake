# USGS 地震カタログ API の設定

サイドバーの `USGS 地震カタログ API` では、USGS から取得する地震カタログの条件を指定します。

![USGS API 条件と基本版の表示](../assets/screenshots/ja/simple.png)

*左サイドバーが検索条件です。条件変更後、メイン領域の取得イベント数と図が更新されたことを確認します。*

## 期間（UTC）

`期間（UTC）` で開始日と終了日を指定します。開始時刻と終了時刻も UTC で指定します。

初期値は直近 30 日間です。長期間・広範囲・低マグニチュードの条件では取得件数が多くなり、表示や取得に時間がかかる場合があります。

## マグニチュード

`マグニチュード` スライダーで、取得する地震の規模を指定します。

- 広域を概観する場合: M4.5 以上など、やや大きめに設定します。
- 日本周辺や狭い範囲を詳しく見る場合: 必要に応じて下限を下げます。
- 大地震だけを確認する場合: M6 以上などに設定します。

## 震源深さ

`震源深さ（km）` で取得対象の深さ範囲を指定します。初期値は 0-700 km です。

浅発地震を中心に見たい場合は上限を 100 km 程度に、沈み込み帯の深発地震まで見たい場合は 700 km 程度まで含めます。

## 緯度・経度

`緯度・経度` の中で検索範囲を指定します。表示地域プリセットを選ぶと、その地域の代表的な範囲が初期値になります。

経度は -180 から 360 まで指定できます。日付変更線をまたぐ地域では、180 度を中心にした範囲指定が使えます。ただし USGS の矩形検索では、経度幅は 360 度以下にする必要があります。

## 並び順

`並び順（Order by）` では、USGS API から返されるデータの優先順位を指定します。

- `time`: 新しい順。最近の地震を確認する場合に使います。
- `time-asc`: 古い順。期間内の変化を古い順に確認したい場合に使います。
- `magnitude`: マグニチュードが大きい順。広範囲で大きな地震を優先したい場合に使います。
- `magnitude-asc`: マグニチュードが小さい順。通常の探索ではあまり使いません。

## 最大取得件数

`最大取得件数（Max events）` は、USGS API から取得する最大イベント数です。設定範囲は 1-20,000 件です。

取得件数が上限に達した場合、条件に合う地震がまだ残っている可能性があります。その場合は、期間を短くする、範囲を狭くする、マグニチュード下限を上げるなどして再取得してください。

## 再取得とキャッシュ

条件を変更するとデータが更新されます。必要に応じてサイドバー下部の `再取得 / APIキャッシュをクリア` を押すと、キャッシュをクリアして再取得できます。
