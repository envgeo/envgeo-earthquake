# 概要

EnvGeo-Earthquake は、地震の震源カタログを対話的に探索するためのアプリです。主なデータソースは USGS Earthquake Catalog API で、期間、マグニチュード、震源深さ、緯度・経度範囲などを指定してデータを取得します。

## できること

- 震源分布を 2D マップで確認する
- 震源の深さを反映した 3D/4D 表示を行う
- マグニチュードまたは震源深さで色分けする
- 日本周辺、全世界、主要な地震多発域プリセットを切り替える
- 任意の A-B 断面を作成して沈み込み帯などの深さ方向分布を見る
- 深度プロファイルで、深さごとの地震数を確認する
- 時系列ヒストグラムで、期間内の発生頻度を確認する
- JMA/NIED などの外部カタログ表をアップロードし、USGS データと比較する
- 取得した USGS カタログを CSV としてダウンロードする

## ページ構成

### 基本版

`4D Earthquake シンプル版` は、USGS カタログを取得して、3D/4D 震源マップと 2D 震源マップを確認するためのページです。まず分布の全体像を把握したい場合に向いています。

### 詳細版

`4D Earthquake 詳細版` は、基本版の機能に加えて、プレート境界表示、任意断面図、深度プロファイル、時系列ヒストグラム、JMA/NIED 比較を行うページです。研究・授業・詳しい探索にはこちらを使います。

## 重要な注意

地震データには速報値が含まれ、後から修正される場合があります。このアプリは研究・教育・探索的解析の補助を目的としたものであり、緊急対応や公共安全上の判断には、気象庁、USGS、自治体などの公式情報を確認してください。

プレート境界は概略的な表示です。公式な断層線、ハザードゾーン、防災判断の根拠としては使用しないでください。
